## Hard requirements

The output must include:

- A scoring table with all six dimensions (Money, Urgency, Reach, Repeatability, Speed, Fit) for every option, scored 1-5.
- A total out of 30 for each option.
- The strongest and weakest factor for each option, in one line.
- A verdict per option using the decision bands (24-30 do, 18-23 test, 12-17 defer, under 12 drop).
- For the top-scoring option: a 7-day proof test with a kill criterion.
- For deferred options: a re-trigger condition (the specific evidence or date that would put them back on the active list).
- Three actions the user can execute today, focused on the top option.

## Hard rules

- Do not inflate scores to justify a preferred answer. If the answer was set before scoring, the score is theater.
- Score Reach as 1 if no specific channel is named.
- Score Fit as 5 only if the user has run 20+ reps in this kind of work — not because they are excited.
- Always identify what the top option *replaces*. Every yes is a no to something else.
