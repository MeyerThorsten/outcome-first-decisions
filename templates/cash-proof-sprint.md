# Cash Proof Sprint — Template

A 1- to 7-day experiment that asks for a concrete commitment from a real buyer. Praise is not proof.

Fill in every field before contacting anyone. The kill criterion goes in writing first.

## Setup

```text
Idea:              [one-sentence offer]
Buyer:             [named segment + active urgent moment]
Problem:           [the pain the buyer feels right now]
Channel:           [where the user will reach this buyer repeatedly]
Sprint window:     [start date → end date, 1-7 days]
Sample target:     [10-30 specific buyers/prospects]
```

## The Ask

The ask is the only part that matters. Make it concrete.

```text
Commitment requested: [payment / deposit / signed pilot / qualified call / referral / application / renewal / value-tied usage]
Specific amount:      [$ / hours / scope]
Deadline for buyer:   [date]
What the user delivers in return: [smallest useful version, manually]
```

Sample ask language:

> "I'm running a 7-day pilot of [offer] for [buyer segment] facing [moment]. The pilot is $[X] and includes [specific deliverable]. I have [N] slots opening [date]. Reply by [deadline] if you want one."

## Thresholds (set before starting)

```text
Strong proof (continue + invest):  [N committed buyers / $X collected / Y signed pilots]
Medium proof (refine + retest):    [N qualified conversations / Y detailed objections]
Weak proof (kill or pivot):        [zero commitments / only compliments / non-buyer attention]
Kill criterion (explicit):         [the result that ends this idea, in writing]
```

## Verdict

After the sprint window closes:

```text
Total contacts:        [N]
Replies:               [N]
Qualified conversations: [N]
Commitments:           [N + form: payment / pilot / call / referral]
Strongest signal:      [highest rung reached]
Weakest signal:        [where buyers fell off]

Verdict:               [keep / change / kill]
What we learned:       [the part worth carrying forward, even if killed]
Next move:             [specific action with deadline]
```

## Common Errors

- Skipping the kill criterion. Without it, weak results get reinterpreted as "early signal."
- Replacing a commitment ask with a survey. Surveys produce intent; commitments produce evidence.
- Counting compliments. Compliments are rung 2; the threshold should require rung 6+.
- Extending the window when results are weak. Extension hides the answer; let the timeline kill the idea cleanly.
