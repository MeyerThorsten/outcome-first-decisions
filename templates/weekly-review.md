# Weekly Review — Template

Twenty minutes. One scoreboard number. Three actions. One stop. One lesson.

Do this on the same day each week. Consistency beats depth.

## Scoreboard

```text
Week of:               [start date]
One number:            [name + current value]
Target by end of season: [value + deadline]
Gap to target:         [number + % of target]
Movement this week:    [+/- value, vs last week]
Direction:             [moving / stuck / regressing]
```

## Keep / Change / Kill

Sort the week's work into three columns:

```text
KEEP (produced evidence, revenue, learning, leverage, or momentum)
- [item — what made it worth keeping]
- [...]

CHANGE (real opportunity, but buyer / offer / channel / price / execution needs adjustment)
- [item — the specific change to make + by when]
- [...]

KILL (consumed time without a credible path to impact)
- [item — what we learned + what we reclaim]
- [...]
```

## Three Actions for Next Week

The three highest-leverage actions on the scoreboard number.

```text
1. [action — owner — deadline — kill criterion if it does not produce result by deadline]
2. [...]
3. [...]
```

If a fourth or fifth action is competing for prime time, name what it replaces.

## One Thing to Stop or Shrink

```text
Stop / shrink:  [item]
Why now:        [the cost it has been carrying]
Capacity returned: [hours/week]
Where capacity goes: [specifically — to which of the three actions above]
```

## One Decision Currently Postponed

The most useful question of the week.

```text
Decision in shadow:  [the call the user has been avoiding]
Why postponed:       [missing evidence / fear / comfort]
What would force it: [the smallest evidence that closes the gap]
By when:             [deadline to either decide or kill]
```

## One Lesson for the Decision Journal

```text
Lesson:              [pattern observed this week, one sentence]
Where it applies:    [next decision this should change]
```

## Self-Check

Before closing the review:

- [ ] One number named, with current value and gap.
- [ ] Three actions named, each with owner and deadline.
- [ ] One thing to stop, with capacity reallocated.
- [ ] One postponed decision named.
- [ ] One lesson logged.

Missing any of these makes the review a meeting, not a decision.
